# Notes UI

Vanilla HTML, CSS, and JavaScript frontend for the Notes Management System. It is served by the Express app in `backend/notes-api/src/server.js`.

The UI supports:

- Listing notes sorted by most recently updated.
- Creating notes.
- Editing title and content.
- Viewing full note details in the editor.
- Deleting notes with confirmation.
- Searching by title and content.
- Loading, empty, validation, and error states.
